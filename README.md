## AnimeciX Desktop (AUR)

This repository contains the necessary files to package [**AnimeciX Desktop**](https://github.com/CaptainSP/animecix-desktop-2) for [AUR](https://aur.archlinux.org).

### Installation

You can install this package using your preferred AUR helper:
```bash
# Using yay
yay -S animecix-desktop

# Using paru
paru -S animecix-desktop
```

## Troubleshooting

If the application fails to launch, try running it from the terminal to see specific error messages:

```bash
animecix
```
